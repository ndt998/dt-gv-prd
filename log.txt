2. CHI TIẾT ĐÃ LÀM
--------------------------------------------------------------------------------

[A] SỬA FILE upload/QR_generator_prd.html (chèn logo thật)
   - Copy logo vào cạnh file: cp public/prd-logo.png upload/prd-logo.png
     (để chạy độc lập vẫn thấy logo; tham chiếu tương đối "prd-logo.png").
   - Thêm biến toàn cục `brandLogo` + hàm loadBrandLogo():
     + new Image(); onload -> render lại preview ngay khi logo tải xong để QR
       đầu tiên đã có logo; onerror -> fallback về chữ PRD cũ.
   - Viết lại drawCenterLogo(logoCanvas):
     + Nếu brandLogo đã sẵn sàng: tính kích thước = ~19% canvas (margins mặc
       định) hoặc 14% (margins="none"), giới hạn tối đa theo module QR; vẽ COVER
       (cắt tròn vừa khung) bằng ctx.save() + arc + clip() + drawImage(), giữ
       nguyên tỷ lệ ảnh gốc, căn đúng tâm QR.
     + Nếu chưa có ảnh: giữ nguyên logic cũ (vòng tròn gradient + chữ "PRD")
       làm phương án dự phòng.
   - Kết quả: QR hiển thị và QR tải về (PNG 512/1024px, SVG nhúng base64) đều
     mang logo PRD thật. Ảnh logo gốc 1024x1024 nên xuất hi-res vẫn nét.

[B] TÍCH HỢP VÀO TRANG CHỦ src/app/page.tsx (Liên kết nhanh -> PRD QRcode)
   - Copy bản đã sửa thành public/prd-qrcode.html (Next.js static export sẽ
     phục vụ tại đường dẫn /prd-qrcode.html; logo tham chiếu prd-logo.png cùng
     thư mục public/ -> hoạt động cả khi mở độc lập lẫn trong iframe).
   - Import thêm icon QrCode từ lucide-react.
   - Mở rộng kiểu QuickLinkItem: thêm cờ tùy chọn openInIframe?: boolean.
   - Thêm phần tử mới vào mảng quickLinks, NGAY SAU "Thư viện số":
     { name: "PRD QRcode", url: "/prd-qrcode.html", icon: QrCode,
       color: "text-cyan-400", openInIframe: true }
   - Sửa handleQuickLinkClick: nếu openInIframe === true -> gọi handleMenuClick
     (mở iframe overlay toàn màn hình, có thanh top "Quay lại" / "Làm mới"),
     ngược lại mở tab mới như các link cũ.
   - Sửa handleRefreshIframe: nhận biết URL tương đối bắt đầu bằng "/" để nối
     tham số chống cache đúng cách (?_r=timestamp) — tránh lỗi Invalid URL với
     link nội bộ /prd-qrcode.html.

[C] KIỂM CHỨNG (không đoán, đều chạy thật)
   - Kiểm tra cấu trúc HTML sau sửa: các hàm loadBrandLogo/drawCenterLogo/
     createPrdLogoPlaceholder/canvas.arc/canvas.clip/drawImage tồn tại; chuỗi
     "prd-logo.png" xuất hiện 3 lần; tag <script> đóng đủ.
   - Build mock môi trường jsdom giả lập browser (canvas 2D context + Image):
     chạy generateQR() -> capture lệnh canvas -> PASS: vòng render cuối là
     drawImage('prd-logo.png') căn giữa tâm (230±34.5 px trên canvas 460px),
     không còn vẽ chữ PRD.
   - npm run build (Next.js static export): PASS.
   - npx serve out + curl: /prd-qrcode.html HTTP 200, /prd-logo.png HTTP 200;
     index.html chứa chuỗi "PRD QRcode".
   - Git: commit 2 lần trên branch main:
     + "Add PRD brand logo to QR generator tool (replace drawn PRD text)"
     + "Add PRD QRcode quick link opening tool in iframe overlay"
